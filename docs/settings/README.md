# Settings

Settings is the screen for the tasks that you do rarely: you change a rule of the app, you correct an ingredient, or you make a backup. This page gives the full picture. Each part has its own page.

## The problem

Five screens are for a day in the kitchen: Today, Menu, Shop, Pantry, and Recipes. Some tasks belong to none of them. The number of meals in your week is a rule for Today and for Menu. A backup has the data of all screens.

An app often puts such tasks in a list with the name "More". That name tells you nothing. You must open the list to learn what is in it, and each new page that has no home goes there.

## The answer: one place with three parts

| Part        | What you do there                                                                 |
| ----------- | --------------------------------------------------------------------------------- |
| Preferences | You change a rule of the app, such as the number of meals in a week.              |
| Ingredients | You correct the name, the unit, the category, or the "perishable" mark of a food. |
| Data        | You make a backup, import one, and load or remove the sample data.                |

- A [preference](preferences.md) is a rule that has a value, and the value is yours.
- The forms of a recipe and of the pantry can make a new [ingredient](../shopping/ingredient-and-product.md). Only this part can change one that exists.
- The phone has the only copy of your kitchen, so the [backup](../shopping/backup.md) must be easy to find.

The Settings screen shows the preferences, because they are short. Ingredients and Data are each a page of their own, and the two buttons at the top of the screen open them.

The three parts have one thing in common: they set the app up, and then you go back to the kitchen.

## A task with a home stays at home

The pantry check and the scan of a barcode are on the Pantry screen, because you are there when you need them. Settings does not repeat such a button. So each task has one place, and you do not ask which of two buttons is the correct one.

## An example

You cook four times in a week, not five. You open Settings and set "Meals in a week" to 4. Today now shows four slots for the week.

On the same screen, you see that the ingredient "Spinach" has no "perishable" mark. You set it. From then on, the app asks you about spinach that is old.
