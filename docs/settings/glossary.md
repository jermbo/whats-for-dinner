# Glossary

The screens, the code, and these pages use the same words. Each word has one meaning. A word that is a link has a page that explains it.

| Word                                           | Meaning                                                                  | Example               |
| ---------------------------------------------- | ------------------------------------------------------------------------ | --------------------- |
| Settings                                       | The place with three parts: preferences, ingredients, and data.          |                       |
| [Preference](preferences.md)                   | A rule of the app that has a value, and you can change the value.        | Meals in a week       |
| [Planning preference](planning-preferences.md) | A preference that changes what the app proposes. It is in a backup.      | Days before a doubt   |
| [Device preference](device-preferences.md)     | A preference that changes how one phone behaves. It stays on that phone. | Timer sound           |
| Default                                        | The value that the app uses until you change a preference.               | 5 meals in a week     |
| [Key](how-a-preference-works.md)               | The name of a preference in the code and in the database.                | `mealsInWeek`         |
| [Fixed](what-stays-fixed.md)                   | Not a preference. The app has one value, or it learns it from the phone. | The currency symbol   |
| Sample data                                    | An example kitchen that you can load to try the app, and remove again.   |                       |
| Hint                                           | A short text or motion that shows how a screen works. It shows one time. | "Throw the top card." |

## Words that we do not use

| Not this                 | But this   | Reason                                                                |
| ------------------------ | ---------- | --------------------------------------------------------------------- |
| More                     | Settings   | "More" does not tell what is on the screen.                           |
| Option                   | Preference | "Option" is a choice in a list, such as a unit or a storage location. |
| A setting, for one value | Preference | "Settings" is the screen. One value on it is a preference.            |
