# Glossary: pantry onboarding

| Word        | Meaning |
| ----------- | ------- |
| Plugin home | The one folder that holds every plugin note **except** recipes. Shopping, food items, the meal plan note, and receipts from past trips live under it or in paths that onboarding sets together with it. You can delete this folder to remove plugin-owned notes from the vault. Recipes do not live here. |
| Larder      | The default **name** of the plugin home folder in the vault: `Larder/`. It is not the **Pantry** part of the kitchen and not the **pantry folder** setting; those are `Larder/Pantry/` and the food notes inside it. |

## Further reading

- [Glossary](../../glossary.md): **Kitchen** is the tab of the plugin, not a folder. **Pantry folder** is the folder whose notes are food items.
