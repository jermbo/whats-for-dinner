# Glossary: one bar for each part

The [decision log](decision-log.md) uses words that the [glossary](../../glossary.md) of the wiki does not have. This page gives each of them one meaning. The page is temporary: a word goes to the wiki glossary when its decision is made.

## The words of the bar

| Word       | Meaning                                                                                    |
| ---------- | ------------------------------------------------------------------------------------------ |
| Bar        | The controls above the list of a part: the find field, the sequence, and the filters.      |
| Find field | The field that shows only the lines that agree with the text that you type.                |
| Sequence   | The order of the lines of a list, such as "By place" or "A to Z". One sequence is on.      |
| Filter     | A rule that shows only one kind of line, such as "Low". A filter does not change the data. |
| Chip       | The small button that puts one filter on or off.                                           |
| Open       | The bar shows all of its controls, in two rows on a phone.                                 |
| Closed     | The bar shows one row: the find field, and the button that opens the bar.                  |
