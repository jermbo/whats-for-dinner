# Glossary: one row for each package

The [decision log](decision-log.md) uses words that the [glossary](../../glossary.md) of the wiki does not have, and it changes the meaning of one word. This page gives each of them one meaning. The page is temporary: a word goes to the wiki glossary when its decision is made.

## The words of a package

| Word         | Meaning                                                                                                   |
| ------------ | --------------------------------------------------------------------------------------------------------- |
| Package      | One container of a food item that you can hold in your hand: one gallon of milk, one carton of eggs.      |
| Package size | The amount of a package when it is new: 1 gal for the milk, 12 for the carton of eggs.                    |
| Left         | The amount that is still in one package: 1/2 gal, or 2 eggs. It is never more than the package size.      |
| Step         | The smallest change that one move of the bar makes: 1 egg, or 1/8 gal.                                    |
| Open package | A package with less than its size left: the carton with 2 eggs.                                           |
| Sealed       | A package with its full size left.                                                                        |

## A word that changes

| Word | Meaning today                                    | Meaning in this initiative                                         |
| ---- | ------------------------------------------------ | ------------------------------------------------------------------ |
| Row  | One food item in one place: one row of the table. | One package of a food item: one row of the table, with its own date. |
