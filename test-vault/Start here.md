# Test vault

This vault is the test kitchen of the plugin. Open this folder in Obsidian with "Open folder as vault".

## Recipes

Seven recipes in the [RecipeMD](https://recipemd.org/specification.html) format. Each is a correct recipe.

## Pantry

One note for each food item. The brands, the other names, the full amount, and the low line are properties. The table has one row for each place.

The pantry starts in this state, on 2026-10-11:

- **Low:** flour and ginger.
- **Out:** milk and taco seasoning.
- **Use soon:** chicken thighs, spinach, avocados, steamed rice, and fresh coriander.
- **More than one place:** eggs, elbow pasta, rice, and spinach.
- **In the freezer:** ground beef. The recipe for tacos has a preparation for it.

## Meal plan

The plan starts with two dinners and one breakfast: chicken curry, tacos, and pancakes. The shopping list for them has milk and taco seasoning.

## Edge cases

One note for each case that the plugin must decide about. The description of each note tells what it tests.
