# Test vault

This vault is the test kitchen of the plugin. Open this folder in Obsidian with "Open folder as vault".

## Recipes

Seven recipes in the [RecipeMD](https://recipemd.org/specification.html) format. Each is a correct recipe.

## Pantry

One note for each food item. The brands and the other names are properties. The table has one row for each place.

## Edge cases

One note for each case that the plugin must decide about. The description of each note tells what it tests.
